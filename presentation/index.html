ENDVEIN: Redefining Backend Performance with Dart

The Problem Statement

Gajah di Ruangan: Stigma Dart di Backend

Kenapa selama ini developer enggan memakai Dart untuk server production bernilai tinggi?

🐢

The Shelf Bottleneck

Package tradisional shelf mengandalkan single-threaded event loop. Di server 16 core, 15 core lainnya tidur pulas (~42k RPS ceiling).

🧠

GC & String Churn

Web framework konvensional mengalokasikan ribuan heap object dan regex string parsing per-request, memicu spike GC latency dan OOM.

🚧

"Gunakan Go Saja"

Kebutuhan throughput tinggi selalu memaksa tim pindah ke Golang/Rust, menciptakan tech stack terfragmentasi antara Fullstack & Mobile.

Deep Systems Engineering

Anatomi Kemacetan I/O Modern

Server tidak lambat karena komputasi matematika, melainkan karena gesekan arsitektural memori dan socket.

🔒

Lock Contention (Go & Node Workers)

Ketika ribuan goroutine atau thread berbagi shared memory heap, OS CPU core menghabiskan cycles untuk menunggu mutex locks dan cache invalidation.

📦

Double / Triple Buffer Copying

Kernel Socket ➔ Native Buffer ➔ Managed Byte Array ➔ UTF-8 String ➔ JSON Map. Setiap step adalah alokasi memori yang memicu Garbage Collection.

Pillar 1: Multi-Core Actor Concurrency

Kernel Socket Sharing: SO_REUSEPORT

Load balancing tingkat kernel tanpa proxy Nginx eksternal, memanfaatkan seluruh core CPU dengan nol lock.

Dart Actor Model final cluster = EndveinCluster( host: '0.0.0.0', port: 8080, workers: Platform.numberOfProcessors, // 10 Cores engineMode: EngineMode.rawSocket, routerFactory: () => appRouter, ); await cluster.run();

Mengapa Bebas Mutex?

Di Dart, setiap Isolate memiliki heap memori sendiri. Tidak ada shared mutable memory antar core.

  • Kernel OS mendistribusikan SYN packet TCP secara hardware-assisted.
  • Zero lock, zero race conditions, zero thread thrashing.
  • Auto-Healing Supervisor: Jika 1 isolate crash, worker baru langsung lahir dalam 2 milidetik.
Pillar 2: Zero-Copy TCP Streaming

Membabat Alokasi Heap: Byte-Level Parsing

Parsing HTTP/1.1 tanpa alokasi string UTF-8 dan tanpa regex di hot-path.

Framework Tradisional (Shelf/Express)

Menerima paket TCP ➔ decode full UTF-8 String ➔ regex split header ➔ hashmap insertion per-header ➔ Ratusan object GC per request.

⚠️ GC Pause spike saat high concurrency

Endvein ZeroCopyHttpParser

Membaca byte array mentah langsung. Header dipindai secara lazy berbasis offset byte ASCII. Alokasi string hanya terjadi jika user sengaja mengakses header tersebut.

⚡ Zero allocation pada request line & headers lookup
Pillar 3: The Secret Weapon

Turbo FFI: Menembus Batas I/O Dart

Arsitektur hybrid C event-loop (pola uWebSockets) terintegrasi langsung dengan Dart isolate thread.

⚡

Native Event Loop

Menggunakan kqueue di macOS/BSD dan epoll di Linux untuk polling jutaan file descriptor dengan O(1) latency.

🚀

Scatter-Gather writev()

Mengirim header HTTP statis dan payload JSON langsung dari buffer terpisah via syscall kernel tanpa penyatuan memori (zero heap copy).

🧵

Thread-Local Scratch Buffer

Buffer 64KB per-thread yang digunakan berulang kali. Menghilangkan 100% malloc() dan free() pada response pipeline.

Developer Ergonomics (Dart 3.3+)

Zero-Cost Typed Safety

Menikmati keamanan tipe data modern tanpa membayar 1 byte pun beban alokasi Garbage Collector.

Dart 3.3 Extension Types // Di-compile ke String murni di runtime extension type const HeaderName(String name) { static const authorization = HeaderName('authorization'); static const contentType = HeaderName('content-type'); } // Di-compile ke int murni di runtime extension type const StatusCode(int code) { static const ok = StatusCode(200); static const unauthorized = StatusCode(401); }

Mengapa Lebih Baik dari Relic/Shelf?

Framework lama membungkus header dan status code dalam class instansiasi (new Header(...)).

  • Auto-complete IDE: Mencegah typo nama header authorization.
  • Zero Memory Footprint: Tidak ada overhead pointer class dan VTable.
  • Type-Safe Responses: ctx.sendJson(data, statusCode: StatusCode.ok).
Production Architecture

Batteries-Included untuk Enterprise

Bukan sekadar engine benchmark, Endvein adalah framework lengkap yang siap menangani beban produksi.

🌲

Radix Trie Router

O(1) static fast-path + Radix Tree untuk parameter dinamis :id dan deep wildcard *filepath.

🛡️

Anti-DoS & Rate Limit

Max header/body limits, idle socket killer, serta RateLimiterStore pluggable (in-memory & Redis).

🤖

AI & SSE Streaming

Dukungan native W3C EventSource via ctx.sse() untuk streaming token LLM secara real-time.

📈

Observability

Prometheus /metrics exporter, structured JSON logger, dan distributed tracing X-Request-Id.

Clean Architecture & Developer Experience

Kerapian Kode Skala Besar & CLI Tool

Membangun arsitektur domain enterprise yang rapi, modular, dan bebas runtime exception traps.

Terminal CLI Scaffolding # 1. Scaffold project Clean Architecture dalam 1 detik: $ endvein create my_fintech_api # 2. Generator Controller, UseCase, Middleware: $ endvein make:controller Payment $ endvein make:usecase ProcessTransfer $ endvein make:middleware AuditLog # 3. Jalankan langsung: $ dart run bin/server.dart

Pola Exception-Free dengan Result<S, F>

Di Dart & Go, melempar throw Exception sangat mahal karena mengkalkulasi stack trace. Endvein mengadopsi functional programming:

return switch (result) { Success(:final user) => ctx.success(user), Failure(:final err) => ctx.fail(err.message, statusCode: 400), };
Putting It All Together

Contoh Server Endvein Lengkap

Hanya dalam 20 baris kode, server multi-core berkekuatan 237.000 RPS siap melayani traffic global.

bin/server.dart import 'package:endvein/endvein.dart'; void main() async { final cluster = EndveinCluster( host: '0.0.0.0', port: 8080, engineMode: EngineMode.turboFfi, // ⚡ 237,000+ RPS Turbo Native routerFactory: () { final router = EndveinRouter(); // Security & Rate Limiting Middlewares router.use(cors()); router.use(rateLimiter(maxRequests: 100, window: Duration(minutes: 1))); // Type-safe Endpoint router.get('/api/users/:id', (ctx) { final userId = ctx.paramInt('id'); return {'user_id': userId, 'status': 'active', 'engine': 'Endvein Turbo'}; }); return router; }, ); await cluster.run(); }
